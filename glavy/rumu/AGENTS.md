# AGENTS.md — инструкции для агентов клетки rumu

Клетка живёт по пяти законам роя (README.md ядра cell-swarm, docs/adr/).

## Что это за клетка

«Руму» — держатель имени РУМУ. Тело клетки (плеер: `cinema.html`,
`catalog.js`, `cord.js`, `autopilot_client.js`) живёт веткой `rumu`
репозитория singulyar: https://github.com/rtynbirf/singulyar/tree/rumu
(пин 5f5d4fb8 на 2026-11-06; живой пин — геном ядра, `make pins`).
Этот репозиторий — имя и мембрана; контента здесь нет (честная заглушка, см. README.md).

## Порядок чтения

1. `README.md` — вход: где живёт тело.
2. `MANIFEST.json` — ДНК клетки (указатель).
3. Геном роя: `cell-swarm/swarm.json`, клетка `rumu`.

## Правила

1. Пин тела (`body_pin`) сверяется живым `git ls-remote` при каждом такте
   ядра (Закон 3: пин «по памяти» не вносится).
2. Перенос тела из ветки singulyar@rumu в самостоятельный репозиторий —
   отдельный такт с ADR в ядре (храповик).
3. Тесты только добавляются; офлайн-first; секреты не коммитятся.
4. Обмен с другими клетками — через геном ядра (пины), не через импорты.
5. Зеркало каталога bldub в теле — см. ADR-0008 ядра: открытой лицензии
   у источника нет, решение за Человеком (PID 1).
